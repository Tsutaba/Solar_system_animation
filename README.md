## Описание проекта
Программа представляет собой интерактивное графическое приложение на языке Python с использованием библиотеки tkinter, визуализирующее движение планет Солнечной системы по круговым орбитам. Проект демонстрирует применение принципов объектно-ориентированного программирования, построение графических примитивов и управление главным циклом анимации.

---

## Функциональные возможности

### Основной функционал
- Отображение центрального неподвижного Солнца и 5 планет.
- Расчет движения космических тел по круговым орбитам с индивидуальной скоростью и радиусом.
- Возможность приостановки анимации (паузы) и сброса углового положения планет.

### Дополнительный функционал
- Отрисовка собственных спутников у Земли, Марса и Юпитера.
- Визуализация динамического пояса астероидов из 150 объектов между Марсом и Юпитером.
- Регулировка скорости течения времени и длины графического шлейфа планет при помощи слайдеров.
- Интерактивное скрытие и отображение линий орбит через интерфейс управления.

## Требования к системе
- Python версии 3.9 или выше.
- Операционная система: Windows / macOS / Linux.
- Внешние зависимости отсутствуют (используются стандартные библиотеки tkinter, math, random).

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Tsutaba/Solar_system_animation
cd Solar_system_animation
```

### 2. Создание и активация виртуального окружения
Для Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
Для macOS / Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление программой
- Space — Пауза и возобновление анимации.
- R / r — Сброс текущих углов планет и астероидов на случайные значения (требуется английская раскладка клавиатуры).
- Графические слайдеры — Изменение скорости времени и длины шлейфа орбит мышью.

## Структура проекта
```text
Solar_system_animation/
├── venv/                        # Папка виртуального окружения
├── .gitignore                   # Список игнорируемых файлов (кэш Python)
├── README.md                    # Документация проекта
├── main.py                      # Точка входа в программу
└── src/
    ├── __init__.py
    ├── app.py                   # Окно приложения, элементы управления и главный цикл
    ├── models/
    │   ├── __init__.py
    │   └── animation_model.py   # Математическая модель положений тел и орбитального движения
    └── renderers/
        ├── __init__.py
        └── renderer.py          # Графический рендеринг объектов на Canvas
```

**Назначение основных модулей:**
- `main.py` — Инициализирует и запускает приложение.
- `animation_model.py` — Отвечает за расчет тригонометрических координат объектов.
- `renderer.py` — Очищает холст и перерисовывает геометрические примитивы планет.
- `app.py` — Организует пользовательский интерфейс, связывает виджеты с моделью и поддерживает постоянную частоту кадров.
